# Seguridad del repositorio

Este repositorio contiene únicamente material académico de laboratorio.

- No se publican contraseñas reales.
- No se publica la PSK real de la VPN.
- `ipsec.secrets.example` contiene marcadores, no credenciales.
- La configuración de FortiGate incluida está sanitizada.
- Las credenciales utilizadas durante la demostración deben mantenerse fuera de GitHub.

Los algoritmos heredados utilizados por la VPN corresponden al entorno de laboratorio y no se recomiendan para despliegues de producción.
