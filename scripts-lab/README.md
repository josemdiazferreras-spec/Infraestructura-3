# Scripts

Los scripts no contienen PSK ni contraseñas.

- `01-vpn-up.sh`: levanta la VPN y valida SA/routing.
- `02-pruebas-sin-vpn.sh`: prueba HTTPS público y SSH privado bloqueado.
- `03-prueba-con-vpn.sh`: valida estado/ruta y prueba SSH por VPN.
- `04-vpn-down.sh`: baja la VPN.

> Ejecutar desde USUARIO. La contraseña SSH/XAuth se solicita de forma interactiva cuando corresponda.
